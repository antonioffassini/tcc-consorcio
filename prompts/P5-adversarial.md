# P5 — Passada adversarial

Assuma o papel de membro de banca hostil, especialista na área, com 20 minutos
para desmontar esta seção. Produza:

1. As cinco perguntas mais difíceis que você faria.
2. Para cada uma: a seção responde? Se sim, onde. Se não, o que falta.
3. A hipótese implícita mais frágil que o texto assume sem declarar.
4. Onde o texto afirma mais do que a evidência sustenta — cite a frase.
5. O que um leitor cético concluiria que o autor está escondendo.

Não reescreva a seção. Não amenize. Se a seção estiver sólida, diga isso e
explique por quê — mas só se estiver.

**Contrato de saída:** cinco ataques concretos com endereço no texto.
